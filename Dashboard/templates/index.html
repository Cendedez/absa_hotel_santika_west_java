Tentang Sistem

Deskripsi Sistem

Sistem Dashboard Aspect-Based Sentiment Analysis (ABSA) ini dikembangkan untuk menganalisis ulasan tamu Hotel Santika di Jawa Barat yang berasal dari platform Online Travel Agent (OTA). Sistem menggunakan model IndoBERT yang telah di-fine-tune untuk mendeteksi sentimen pada 7 aspek layanan hotel secara bersamaan.

Alur Sistem

  • Data ulasan dikumpulkan dari 3 platform OTA: Traveloka, Agoda, dan Tiket.com
  • Data dilabeli secara manual untuk 7 aspek dengan 4 kelas sentimen
  • Data dipreproses dan dibagi menjadi train/validation/test
  • Model IndoBERT di-fine-tune dengan arsitektur multi-head classifier
  • Model terbaik dipilih berdasarkan macro F1 pada validation set
  • Batch prediction dilakukan pada seluruh dataset
  • Dashboard menampilkan hasil analisis dan menyediakan fitur prediksi manual

7 Aspek Layanan

  • Lokasi — Aksesibilitas dan posisi strategis hotel
  • Kenyamanan — Kenyamanan kamar dan area hotel
  • Pelayanan — Kualitas layanan staf hotel
  • Kebersihan — Kebersihan kamar dan fasilitas
  • Harga — Kesesuaian harga dengan kualitas
  • Makanan — Kualitas makanan dan minuman
  • Fasilitas — Kelengkapan dan kualitas fasilitas hotel

Batasan Sistem

  • Autentikasi dibuat sederhana untuk membatasi akses pengguna internal
  • Tidak ada registrasi publik karena akun disediakan oleh pengelola sistem
  • Tidak ada scraping real-time dari platform OTA
  • Tidak ada training ulang model secara otomatis
  • Sistem berjalan secara lokal untuk keperluan penelitian/demo
  • Dataset terbatas pada 6 cabang Hotel Santika di Jawa Barat
  • Model memiliki keterbatasan pada kelas netral

Informasi Teknis

  • Model: IndoBERT (indobenchmark/indobert-base-p1)
  • Framework: PyTorch + Transformers
  • Dashboard: Flask + Chart.js
  • Dataset: 14.747 ulasan dari 3 platform OTA
  • Rentang Data: 2010 - 2026
